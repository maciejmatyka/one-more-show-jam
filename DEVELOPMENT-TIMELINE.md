## What the archive does not claim

- Historical heist renders are not final puppet-game scenes.
- A proposed feature is not an implemented feature.
- Automated QA is not independent human testing.
- Synthetic 8/12/25/100 counters are not one hundred manually played shows.
- A measured score is not guaranteed across hardware or engine versions.
- The first private Git commit imported existing work; it was not backdated into imaginary earlier commits.
- The source capture uses automated cuts. The final film's soundtrack is mixed from licensed project assets.
- No external conversation that was never supplied is claimed as captured.
