# Production statistics - scope and method

Closing page revised on **15 November 2026**. Measurements were frozen on **14 November 2026, 23:27 CET**; they are not a live counter.

**Human-directed. Built with Codex. Run @ UNREAL.**

- **65 hours elapsed:** rounded from 64 h 47 min, first visible prompt (12 November, 06:25 CET) to the final Android correction report (14 November, 23:12 CET). Calendar time includes breaks; it is not labour time.
- **108 recorded inputs:** 108 numbered user records in the private archive through P0108, including the statistics request: 89 prompts/comments and 19 question replies or confirmations. Existing full conversation exports preserve their earlier snapshot of 87 user messages; they were not silently expanded to this count.
- **61 Git restore points:** the number of named milestone tags preserved at measurement, not a claim of 61 different finished games.
- **Two playable platforms:** Windows v0.21.0 RC2 and Android v0.21.1 RC2.1. This does not imply identical graphics, performance or device-test coverage.

## Further measured figures

18,181 physical source lines: 4,126 in the current Unreal project Source (including QA and capture code), 13,555 in production tools and 500 in seven HTML prototypes. Blank lines and comments are included; some lines contain several statements. Unreal Engine source, engine-derived plugin source and archived build copies are excluded. This is retained-source length, not all lines ever written or deleted.

Download packages: Windows 408,904,212 bytes; Android 186,576,654 bytes. Workspace: 230,996,559,230 logical bytes across 113,734 files, including versions, media, toolchains, build caches and Git. MB means 1,000,000 bytes. This is not allocated disk space and not the game's download size.

The available log contains about 26 h 13 min of Codex turns within the development interval, including tool calls, compilation, tests, rendering and waits. Overlapping intervals were merged. Pure generation time, human typing time and percentage shares of authorship were not measured. No percentage split is asserted.

## Human and tool contributions

Maciej Matyka supplied the original shadow-matching concept and sketch, selected the direction, reviewed builds and tester feedback, and made the final decisions. Codex implemented and revised code, procedural art and animation, tools, tests, packaging, editing and documentation. These roles do not measure the relative creative value of each contribution.
