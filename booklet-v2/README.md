# The Last Show - Glass Box, edition 02

**by Maciej Matyka | Development with OpenAI Codex | 14 November 2026**

[Read the illustrated booklet](https://maciejmatyka.github.io/one-more-show-jam/booklet-v2/) · [Download the PDF](TheLastShow-GlassBox-v2.pdf) · [Prompt translations](PROMPTS-EN.md) · [Evidence](EVIDENCE.md) · [Credits](SOURCES.md)

Prologue, five acts and an epilogue tell the development story: seven playable auditions, the human's physical shadow-matching brief, an intentionally rejected reference-world experiment, story and visual iteration, native input repairs, Android failures and recovery, and a frame-verified trailer.

Twenty translated prompt excerpts are paired with decisions and outcomes. The images are documented crops of existing Unreal captures, including motion sequences and before/after details. Synthetic test results are explicitly distinguished from real Chaos runs and human feedback. A game-inspired progress bar marks the reading position on every page.

This edition documents game v0.20.1. It is an additive replacement for jury reading, not an overwrite of earlier RC1 records and not an automated jam entry. The raw Polish archive and source repository remain private.
